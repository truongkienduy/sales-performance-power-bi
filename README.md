# Sales Performance Power BI
## Introduction
This user story outlines the specifications for building two dashboards using Power BI to help stakeholders, including sales managers and executives to analyze sales performance and customers.
## Sales Dashboard | Requirements
### Dashboard Purpose
The purpose of sales dashboard is to present an overview of the sales metrics and trends in order to analyze year-over-year sales performance and understand sales trends.
